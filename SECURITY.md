# Política de segurança

Se encontrar uma vulnerabilidade, **não inclua dados sensíveis ou instruções de exploração em uma issue pública**. Prefira a função **Report a vulnerability** da aba Security do repositório, se estiver ativada. Caso contrário, peça um canal privado de contato à mantenedora sem divulgar detalhes do risco.

Abrangência: código estático desta versão. Não oferecemos garantia de disponibilidade, confidencialidade de aparelhos compartilhados ou segurança dos sites externos acessados pelos links.

Consulte também `docs/SEGURANCA.md`.
