# Como contribuir

Obrigada por contribuir! Use Issues para sugerir ajustes de acessibilidade, navegação, perguntas de estudo ou problemas de tradução. Para código, prefira uma branch curta e Pull Request explicando objetivo, arquivos alterados e testes executados. Não compartilhe experiências espirituais íntimas, dados pessoais ou detalhes de outras pessoas em Issues públicas.

Mudanças nas reflexões devem citar a referência bíblica relevante, considerar contexto histórico e literário e evitar apresentar opiniões como única interpretação cristã possível.

Confira `AGENTS.md` para regras de produto e `docs/TESTES.md` antes de submeter alterações.
